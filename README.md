# NineHook
NineHook is a C++ modding framework for the PC game 9 Days. it injects into the game's memory as a proxy (dxgi.dll) for automatic loading. It includes a pattern scanner for game updates, a safe memory patcher, and a developer console for real-time diagnostics.
